02 / MÉTODO

Dos preguntas.
Una respuesta honesta.

El observatorio envía una solicitud HEAD / a HTTP y otra a HTTPS. No inicia sesión, no sigue enlaces ni intenta vulnerar el sitio.

01

¿Responde HTTPS?

Se comprueba la conexión TLS y la respuesta de la página principal. La validación normal del certificado permanece activada.

02

¿Qué hace HTTP?

Se observa si la página principal redirige a una dirección https:// o si sigue respondiendo por HTTP.

03

¿Qué podemos concluir?

El informe distingue redirección, HTTP sin redirección, HTTPS disponible, HTTPS no verificado y resultados no concluyentes.

03 / ALCANCE

Lo que esta señal significa

↗

Una raíz, no todo el sitio

Solo se observa /. Otras rutas, subdominios o servicios pueden comportarse de otro modo.

⌁

Una medición puntual

Redes, firewalls y configuraciones cambian. Cada resultado incluye la hora en que se obtuvo.

◇

Transporte, no auditoría

HTTPS protege el transporte. Esta herramienta no evalúa la seguridad de la aplicación ni busca vulnerabilidades.
